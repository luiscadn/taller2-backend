====================================================================
INSTRUCCIONES DE DESPLIEGUE Y ACTUALIZACIÓN - FASE 2 (Backend API - HU4 & HU5)
REPOSITORIO: taller2-backend
ENTORNO OBJETIVO: Servidor Backend (Linux/Ubuntu) - Puerto: 8080
====================================================================

1. DETENER EL PROCESO ANTERIOR (Fase 1 / HU3):
   - Identificar y detener el proceso uvicorn en ejecución:
     pkill -f uvicorn || true

2. ACTUALIZAR CÓDIGO FUENTE:
   - Descomprimir el paquete de actualización de la Fase 2 ('entrega_fase2_backend.zip'):
     unzip -o entrega_fase2_backend.zip -d /opt/taller2-backend
     cd /opt/taller2-backend

3. CONFIGURACIÓN CRÍTICA DE PERMISOS DE ESCRITURA (System of Record - SoR):
   - Asegurar la existencia de sor_history.txt y conceder permisos de escritura (chmod 666):
     touch sor_history.txt
     chmod 666 sor_history.txt

4. INICIAR EL SERVICIO EN SEGUNDO PLANO (PUERTO 8080):
   - Iniciar el servidor FastAPI con los nuevos servicios (/divide y /health):
     source venv/bin/activate
     nohup uvicorn main:app --host 0.0.0.0 --port 8080 > backend.log 2>&1 &

5. VERIFICACIÓN DE OPERATIVIDAD (PRUEBA DE HUMO):
   - Probar endpoint de Telemetría / Health Check (HU5):
     curl http://localhost:8080/health

   - Probar endpoint de División exitosa (HU4):
     curl -X POST http://localhost:8080/api/divide \
          -H "Content-Type: application/json" \
          -d '{"a": 20, "b": 4}'

   - Probar validación HTTP 400 Bad Request por división entre cero (HU4):
     curl -i -X POST http://localhost:8080/api/divide \
          -H "Content-Type: application/json" \
          -d '{"a": 10, "b": 0}'
