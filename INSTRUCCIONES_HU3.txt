INSTRUCCIONES DE ACTUALIZACIÓN Y PERMISOS - HISTORIA DE USUARIO 3 (Backend API)
REPOSITORIO: taller2-backend
ENTORNO OBJETIVO: Servidor Backend (Linux/Ubuntu) - Puerto: 8080
====================================================================

1. DETENER EL PROCESO ANTERIOR (HU2):
   - Identificar y detener el proceso uvicorn en ejecución:
     pkill -f uvicorn || true

2. ACTUALIZAR CÓDIGO FUENTE:
   - Descomprimir el paquete de actualización 'entrega_HU3_backend.zip':
     unzip -o entrega_HU3_backend.zip -d /opt/taller2-backend
     cd /opt/taller2-backend

3. CONFIGURACIÓN CRÍTICA DE PERMISOS DE ESCRITURA (System of Record - SoR):
   - Crear explícitamente el archivo de persistencia local y garantizar permisos de lectura/escritura (chmod 666):
     touch sor_history.txt
     chmod 666 sor_history.txt

4. INICIAR EL SERVICIO NUEVAMENTE:
   - Iniciar el servidor FastAPI con persistencia SoR habilitada:
     source venv/bin/activate
     nohup uvicorn main:app --host 0.0.0.0 --port 8080 > backend.log 2>&1 &

5. VERIFICACIÓN DE OPERATIVIDAD (PRUEBA DE HUMO):
   - Probar endpoint de historial SoR (HU3):
     curl http://localhost:8080/api/history
