INSTRUCCIONES DE ACTUALIZACIÓN - HISTORIA DE USUARIO 2 (Backend API)
REPOSITORIO: taller2-backend
ENTORNO OBJETIVO: Servidor Backend (Linux/Ubuntu) - Puerto: 8080
====================================================================

1. DETENER EL PROCESO ANTERIOR (HU1):
   - Identificar y detener el proceso uvicorn en ejecución:
     pkill -f uvicorn || true

2. ACTUALIZAR EL CÓDIGO FUENTE:
   - Descomprimir el paquete de actualización 'entrega_HU2_backend.zip':
     unzip -o entrega_HU2_backend.zip -d /opt/taller2-backend
     cd /opt/taller2-backend

3. INICIAR EL SERVICIO NUEVAMENTE:
   - Iniciar el servidor FastAPI con los nuevos endpoints (Suma, Resta, Multiplicación):
     source venv/bin/activate
     nohup uvicorn main:app --host 0.0.0.0 --port 8080 > backend.log 2>&1 &

4. VERIFICACIÓN DE OPERATIVIDAD (PRUEBA DE HUMO):
   - Probar endpoint de Resta (HU2):
     curl -X POST http://localhost:8080/api/subtract \
          -H "Content-Type: application/json" \
          -d '{"a": 20, "b": 8}'

   - Probar endpoint de Multiplicación (HU2):
     curl -X POST http://localhost:8080/api/multiply \
          -H "Content-Type: application/json" \
          -d '{"a": 4, "b": 6}'
