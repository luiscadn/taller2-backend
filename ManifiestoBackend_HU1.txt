MANIFIESTO DE DESPLIEGUE MANUAL - HISTORIA DE USUARIO: HU1 (Backend)
REPOSITORIO: taller2-backend
ENTORNO OBJETIVO: PC 1 (Servidor Backend - Linux/Ubuntu)
====================================================================

1. REQUISITOS PREVIOS Y DEPENDENCIAS DEL SISTEMA:
   - Asegurarse de tener instalado Python 3.10+ y pip.
   - Si no están instalados, ejecutar en la terminal del PC 1:
     sudo apt update && sudo apt install -y python3 python3-pip python3-venv ufw

2. CONFIGURACIÓN DEL CORTAFUEGOS (UFW):
   - El puerto autorizado para exponer el Backend es el 8080.
   - Ejecutar como usuario con permisos sudo:
     sudo ufw default deny incoming
     sudo ufw default allow outgoing
     sudo ufw allow 8080/tcp
     sudo ufw --force enable

3. EXTRACCIÓN Y INSTALACIÓN DEL CÓDIGO:
   - Descomprimir 'entrega_HU1_backend.zip' en el directorio /opt/taller2-backend:
     sudo mkdir -p /opt/taller2-backend
     sudo unzip -o entrega_HU1_backend.zip -d /opt/taller2-backend
     cd /opt/taller2-backend

   - Crear y activar el entorno virtual de Python:
     python3 -m venv venv
     source venv/bin/activate

   - Instalar dependencias del proyecto:
     pip install -r requirements.txt

4. EJECUCIÓN DEL SERVICIO:
   - Iniciar el servidor FastAPI mediante Uvicorn escuchando en la IP 0.0.0.0:
     nohup uvicorn app.main:app --host 0.0.0.0 --port 8080 > backend.log 2>&1 &

5. CRITERIO DE VERIFICACIÓN LOCAL (PRUEBA DE HUMO PARA OPS):
   - Ejecutar localmente en el PC 1 para confirmar que el puerto responde:
     curl -X POST http://localhost:8080/api/sum \
          -H "Content-Type: application/json" \
          -d '{"a": 5, "b": 10}'
   - Respuesta esperada: {"operation":"sum","result":15.0}

====================================================================
EN CASO DE FALLO:
- Si el comando curl retorna error, ver el archivo 'backend.log' y emitir 
  un ticket escrito describiendo el mensaje de error del log.
